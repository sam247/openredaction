## Log Sanitization

Redact PII from application logs before storage or analysis so sensitive values
never land in Datadog, Elastic, or CloudWatch.

### Problem

Logs routinely contain:

- User emails in error messages
- Phone numbers in request logs
- IPs and session identifiers
- Free-text payloads pasted into debug traces

### Solution

Run each log message through OpenRedaction before the transport writes it.

### Implementation

```javascript
import { OpenRedaction } from 'openredaction';
import winston from 'winston';

const redactor = new OpenRedaction({
  preset: 'gdpr',
  redactionMode: 'placeholder',
});

const redactFormat = winston.format((info) => {
  // Winston format hooks are sync — queue redaction in the transport path,
  // or redact at the call site before logger.info(...). Prefer call-site:
  return info;
});

async function infoSafe(logger, message, meta = {}) {
  const { redacted, detections } = await redactor.detect(String(message));
  logger.info(redacted, {
    ...meta,
    piiDetected: detections.length > 0,
  });
}

const logger = winston.createLogger({
  format: winston.format.combine(
    winston.format.timestamp(),
    winston.format.json(),
  ),
  transports: [
    new winston.transports.Console(),
    new winston.transports.File({ filename: 'app.log' }),
  ],
});

await infoSafe(logger, 'User john@example.com logged in from 192.168.1.1');
// Logs a placeholder-redacted message, not the raw email / IP
```

### Tips

- Redact **before** serialization — do not rely on grep after the fact
- Keep a separate audit channel that records *that* redaction happened, never
  the raw PII
- Prefer structured fields (`userId`) over embedding identifiers in free-text
  messages

## Email Scrubbing

Sanitize inbound or outbound email bodies before CRM sync, ticketing, or LLM
summarization.

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'gdpr' });

async function scrubEmail(emailContent) {
  const { redacted, detections } = await redactor.detect(emailContent.body);

  return {
    ...emailContent,
    body: redacted,
    piiCount: detections.length,
  };
}

const clean = await scrubEmail({
  subject: 'Support request',
  body: 'Please call me on 07700900123 or email jane@acme.com',
});
```

Also see [Handle PII in support tickets](https://openredaction.com/blog/pii-in-support-tickets).

## Chat Redaction

Redact chat messages at ingest so search indexes and agent copilots never store
raw identifiers.

```javascript
import express from 'express';
import { OpenRedaction } from 'openredaction';

const app = express();
const redactor = new OpenRedaction({
  preset: 'gdpr',
  deterministic: true,
});

app.use(express.json());

app.post('/api/messages', async (req, res) => {
  const { text, channelId } = req.body;
  const { redacted, redactionMap, detections } = await redactor.detect(text);

  // Persist only redacted text in the chat store / vector index
  await saveMessage({ channelId, text: redacted, piiCount: detections.length });

  // Optional: keep redactionMap in a privileged, short-lived session store
  // if authorised tools need restore later
  res.json({ ok: true, text: redacted });
});
```

## Data Export

Sanitize JSON exports before handing them to analysts or third parties.

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'hipaa' });

async function exportUserData(userId) {
  const data = await getUserData(userId);
  const { redacted } = await redactor.detect(JSON.stringify(data));
  return JSON.parse(redacted);
}
```

For field-level control, redact specific strings rather than the whole document
when structure must stay perfectly intact.

## API Gateway Integration

Put redaction at the gateway so every route inherits the same policy.

### Option A — `@openredaction/express` middleware

```javascript
import express from 'express';
import { openredactionMiddleware } from '@openredaction/express';

const app = express();
app.use(express.json());

app.use(
  openredactionMiddleware({
    autoRedact: true,
    fields: ['prompt', 'message', 'content', 'body'],
  }),
);

app.post('/v1/chat', (req, res) => {
  // Sensitive fields already redacted
  res.json({ body: req.body, pii: req.pii });
});
```

### Option B — Manual LLM proxy

```javascript
import OpenAI from 'openai';
import { OpenRedaction } from 'openredaction';

const openai = new OpenAI();
const redactor = new OpenRedaction({ redactionMode: 'placeholder' });

async function safeCompletion(userPrompt) {
  const { redacted } = await redactor.detect(userPrompt);

  return openai.chat.completions.create({
    model: 'gpt-4.1-mini',
    messages: [{ role: 'user', content: redacted }],
  });
}
```

## Batch Processing

### Simple parallel batch

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'gdpr' });
const documents = await loadDocuments();

const results = await Promise.all(
  documents.map(async (doc) => {
    const { redacted, detections } = await redactor.detect(doc.text);
    return { id: doc.id, redacted, piiCount: detections.length };
  }),
);
```

### Larger jobs

```javascript
import { OpenRedaction, createBatchProcessor } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'gdpr' });
const processor = createBatchProcessor(redactor);

// See package docs for BatchProcessor options and progress hooks
const batchResult = await processor.process(documents.map((d) => d.text));
```
