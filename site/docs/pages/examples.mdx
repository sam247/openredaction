# Examples

Common use cases and code examples for OpenRedaction. All samples use the
current API: create an `OpenRedaction` instance and call async `detect()`.

For pipeline design (LLM gateways, RAG, citations, telemetry), see the
[PII redaction guide](https://openredaction.com/pii-redaction).

## Basic Examples

### Redacting Email Addresses

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction();
const text = 'Contact us at support@example.com';
const result = await redactor.detect(text);

console.log(result.redacted);
// e.g. "Contact us at [EMAIL_…]"
```

### Redacting Phone Numbers

```javascript
const text = 'Call me at (555) 123-4567';
const result = await redactor.detect(text);

console.log(result.redacted);
// e.g. "Call me at [PHONE_…]"
```

### Redacting Multiple PII Types

```javascript
const text = `
  Name: John Doe
  Email: john@example.com
  Phone: 555-123-4567
  SSN: 123-45-6789
`;

const result = await redactor.detect(text);
console.log(result.redacted);
console.log(result.detections.map((d) => d.type));
```

## Advanced Examples

### Custom Redaction Mode

```javascript
import { OpenRedaction } from 'openredaction';

// Mask middle characters — useful for internal dashboards
const redactor = new OpenRedaction({
  redactionMode: 'mask-middle',
});

const result = await redactor.detect('Contact john@example.com');
console.log(result.redacted);
// e.g. partial mask of the email value
```

Other modes: `placeholder` (default), `mask-all`, `format-preserving`,
`token-replace`.

### Compliance Preset

```javascript
const redactor = new OpenRedaction({
  preset: 'gdpr',
  redactionMode: 'placeholder',
  deterministic: true,
});

const result = await redactor.detect(text);
```

### Processing Files

```javascript
import fs from 'fs';
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'gdpr' });
const fileContent = fs.readFileSync('document.txt', 'utf8');
const result = await redactor.detect(fileContent);

fs.writeFileSync('redacted.txt', result.redacted);
```

## Integration Examples

### Express.js Middleware

Prefer the dedicated package when you want automatic body scrubbing:

```javascript
import express from 'express';
import { openredactionMiddleware } from '@openredaction/express';

const app = express();
app.use(express.json());
app.use(openredactionMiddleware({ autoRedact: true }));

app.post('/api/submit', (req, res) => {
  // req.body fields are redacted in-place; req.pii has detection metadata
  res.json({ body: req.body, pii: req.pii });
});
```

Or call the core library on a single route:

```javascript
import express from 'express';
import { OpenRedaction } from 'openredaction';

const app = express();
const redactor = new OpenRedaction({ preset: 'gdpr' });

app.use(express.json());

app.post('/api/redact', async (req, res) => {
  const { text } = req.body;
  const result = await redactor.detect(text);
  res.json(result);
});
```

### Log Processing

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction({ preset: 'gdpr' });

async function processLog(logEntry) {
  const result = await redactor.detect(logEntry.message);

  return {
    ...logEntry,
    message: result.redacted,
    piiDetected: result.detections.length > 0,
  };
}
```

### Batch Processing

```javascript
import { OpenRedaction } from 'openredaction';

const redactor = new OpenRedaction();
const texts = [
  'Email: user1@example.com',
  'Phone: 555-111-2222',
  'Name: Jane Smith',
];

const results = await Promise.all(texts.map((text) => redactor.detect(text)));

results.forEach((result, index) => {
  console.log(`Text ${index + 1}:`, result.redacted);
});
```

You can also use `OpenRedaction.detectBatch(...)` or `createBatchProcessor`
for larger jobs — see the package API reference.

## Use Cases

### Chat Application

Redact PII from chat messages before storing or displaying:

```javascript
app.post('/api/messages', async (req, res) => {
  const { message } = req.body;
  const { redacted } = await redactor.detect(message);

  await saveMessage(redacted);
  res.json({ success: true });
});
```

### Data Export

Redact PII before exporting data:

```javascript
async function exportUserData(userId) {
  const data = await getUserData(userId);
  const { redacted } = await redactor.detect(JSON.stringify(data));
  return JSON.parse(redacted);
}
```

### API Gateway / LLM Proxy

Redact free-text fields before they leave your network:

```javascript
app.use(async (req, _res, next) => {
  if (req.body?.prompt && typeof req.body.prompt === 'string') {
    const { redacted } = await redactor.detect(req.body.prompt);
    req.body.prompt = redacted;
  }
  next();
});
```
